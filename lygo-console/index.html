Install

Hand it to your agent

This product is built to be installed by an AI agent. A human can do it by hand — but the last mile, wiring the dispatcher, the model route and the browser link, is where hand-installs stall. An agent finishes it.

  1. Give your agent the runbook. AGENT-INSTALL.md — on the release page and inside the installer. Preflight, silent install, verification, wiring checklist.

  2. It installs and verifies. Console on 127.0.0.1:9641, browser on 9337/9333, Forge on 8796 — all loopback.

  3. It wires the loop. Model route to the local engine, browser endpoints handed to both apps, one real task dispatched end to end, then swarms.

  4. You get a report. What answered, what it could not verify, what it left alone.

Prefer to do it yourself? The installer shows its notes when it finishes, and INSTALL.md covers the manual path.

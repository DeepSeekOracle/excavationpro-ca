# HAVEN DESK: THE LONG LOST PC

**Profile:** Web 2D / narrative desk  
**Engine:** existing LYGO 98 static desk  
**Status:** playable vertical slice  
**Owner:** Producer / Lightfather

## Pitch

You find a computer that was left on. Its calendar can open dates in the past and future. Reconstruct the owner's life, solve the rooms, and decide what to do with the one private date the machine refused to index.

## Player fantasy

Be the visitor who reads a life the way an archaeologist reads a site: through documents, public records, old interfaces, strange gates, and one room that is only a candle.

## Audience and platform

- Audience: readers, puzzle players, LYGO/Eternal Haven curious, retro-interface fans.
- Platform: web, desktop-first; mobile playable.
- Target machine / low-end preset: 8 GB RAM laptop, integrated GPU; no WebGL required.
- Input: mouse, keyboard, touch.
- Time: 20–60 minute first sitting; expandable by date rooms.

## Pillars

1. **The desk is the world** — test: every new feature can be opened from the LYGO 98 desktop.
2. **A date is a room** — test: each date has story, documents, a gate and a consequence.
3. **Public facts, private fiction** — test: every real claim has a link; every invented scene is labeled.
4. **One more day** — test: each solved room opens at least one new question.

## Non-goals

- No multiplayer.
- No paid assets, API, subscription, credits or store.
- No copied Windows/Microsoft assets or branding.
- No private facts presented as public record.
- No 3D action combat or open world in this slice.
- No broad rewrite outside the game folder.

## Scope

- Vertical slice: 24 date rooms, hidden 1980 room, 5 gate types, calendar map/month/casebook/sources, Wire Chat, remastered saver.
- First release: this slice on the existing games hub.
- Not in this release: full voice cast, 3D character game, localization, cloud saves, store build.

## Success test

A new player can boot the desk, find the first foundation, unlock a second era, and reach the hidden 1980 room using only in-game clues — with no console errors, no external walkthrough, and no private data.

A browser that keeps the page.

LYGO Browser is a Windows browser for daily reading and for an agent on the same machine. Tabs, history, downloads, and print work like any other browser. The extra is a bookmark archive you own, a vault Windows encrypts to your account, and a local bridge nothing outside this PC can call.

What you are downloading

Read

A real browser

Chromium through WebView2. Tabs you can reorder, find in page, zoom, history, downloads, print to PDF, and session restore. The home page opens excavationpro.ca. You can change that.

Keep

Bookmark Bible

Folders, tags, pins, and search. One action files the raw HTML, the text, a Markdown copy, a full-page image, and a SHA-256 of what you saved. The copy stays on your disk.

Drive

Agent, locally

A loopback API on port 9337 and a Chrome DevTools endpoint on 9333, so Playwright or another tool on this PC can open a tab. Posts need a token created on first run. Omni, the in-browser agent window, opens with Ctrl+Shift+O. Light mode needs no model.

The credential vault is sealed with Windows DPAPI. Passwords are not written in plaintext. The browser does not ship with an account, a cloud login, or a phone-home. The 2.0.0 installer was built from the desktop app after a public pass: bookmarks, history, the vault, the profile, and builder paths are not in the file.

Install

  1. Download LYGO_BROWSER_2.0.0_SETUP.exe. Per-user. No administrator prompt.
  2. Run it. The app lands in %LOCALAPPDATA%\LYGO\Browser\app and a Start menu shortcut is created.
  3. If Windows asks for the .NET 9 Desktop Runtime, install that from Microsoft, then launch again. WebView2 is already on current Windows.
  4. Making it the default browser is your click, in Settings, Default apps. The installer does not take that from you.

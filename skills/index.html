What is in every pack

  • SKILL.md — the complete instructions, including when to use it, the method, templates and failure tables.
  • references/ — source notes, official links and deeper troubleshooting tables.
  • templates/ — copyable code starts, not placeholder fragments.
  • scripts/ — runnable helpers where the skill needs one.
  • CHANGELOG.md and LICENSE — release history and MIT-0 terms.

How to use a ZIP

  1. Download the pack and unzip it into your agent’s skills directory, or read the raw SKILL.md first.
  2. Check the requirements and permissions the skill declares. None of these packs require a secret to read.
  3. Run the templates in a scratch directory first. The PowerShell, Rust and Python examples were exercised on this machine; the PyO3 build is a shape, not a prebuilt extension.
  4. Keep the license file with the pack when you republish or vendor it. The text is MIT-0; the music and essays on this domain are not.

Why the readable page matters

A ZIP you cannot inspect is a trust problem. Every package has a public detail page with the full text, the license, the release version and a direct raw file. The SHA-256 manifest covers the downloadable archives so a mirror can be checked without trusting this page.

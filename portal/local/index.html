Full disclosure

What the harness does, what it does not do, and what leaves your machine.

What it reads

Your local loopback ports and the model list returned by the selected engine. Optionally, a local engines.json you create.

What it sends

Only your prompt, to the selected engine on 127.0.0.1. No prompt is sent to excavationpro.ca. No analytics endpoint is called by the harness.

What it stores

No chat history is written to disk. The browser tab holds the current answer. The harness logs startup and engine status to its own console.

What it will add later

Phase 2 pairing sends a one-time code and session token to the relay. That will be disclosed and opt-in. The relay cannot see prompts if WebRTC is used; with a WebSocket relay it can, so that choice will be explicit.

What it never does

No arbitrary command from the website, no LAN scan, no open proxy, no silent auto-start, no remote shell, no model upload.

Your responsibility

Model licences, hardware limits, content you generate, and any API or tip you choose. The harness is a local tool, not a hosted service.

        ⇄ Compare bench
        two lanes, one prompt, side by side, then one refined answer
        
          
          
        
      

      

      
Put the same prompt to two or more models at once, then read them side by side. From there, one click turns the comparison into something you can use: press the + on the strongest segments of each answer and Assemble them, your own picks, in order, verbatim, tagged to the answer each came from and written without spending a call, or leave nothing picked and press ⇄ Synthesize to send every answer to one chosen lane and get a single refined answer back, with the line saying what it leaned on. If you have picked segments, Synthesize sends only those, so the fuse is sharp and costs less. One answer per run joins the conversation, so the log stays a conversation. Keys pasted in a lane stay in this tab’s memory, never in browser storage; nothing here is uploaded and no answer is stored anywhere but your own browser. A lane set to the same provider as the top box shares the key you already pasted there. A custom lane can point at any OpenAI-compatible URL (two self-hosted servers, two labs), and 127.0.0.1/localhost is allowed by this page’s own policy. Each run spends one call per ready lane on your keys (the synthesis spends one more), and the seconds and tokens of each answer are shown with it.

        Which routes this page can really use, and what each one costs
        

      

      
A console draws one picture at a time (3 per 10 minutes per address): seconds on a free card, about
        5 minutes on the CPU route the engine picks while the chat model holds the card. A key route bills your own
